Who I Am

about-me.md

Hi, I'm Soumadeep Dey, a third-year Computer Science student at Netaji Subhash Engineering College, Kolkata, and a Java backend developer in the making. I like the part of software that users never see: clean APIs, well-designed databases, secure authentication and systems that keep working when real people use them.

My foundation is Core Java, JDBC, Maven and Hibernate, which I built up into the Spring ecosystem: Spring MVC, Spring Boot, Spring Data JPA and REST APIs. I have worked with Spring Security, JWT and Google Sign-In to protect applications, PostgreSQL for data, and I've explored microservices and Spring AI, including a 55-hour Udemy certification on Spring, Spring Boot and Spring AI.

I learn by building. MoneyManager is a personal finance tracker with JWT auth, Google Sign-In, dashboards and Excel reports. CineStage is a cinema ticket booking platform with cities, theatres, screens, seats, shows and bookings, plus live posters from the TMDB API. I containerized and deployed both, with Docker, Render, Neon and Netlify, so each one is live and not just on my laptop.

Alongside development, I keep sharpening my problem solving through DSA and competitive programming. I hold a 5-star Java and a 4-star Problem Solving badge on HackerRank, and I spent a year as a core member of the CtrlZ community, helping host DSA and CP contests. I also document what I learn on LinkedIn, because explaining something is the fastest way to understand it.

Right now I'm looking for Java backend internships and full-time backend roles where I can contribute, learn from experienced engineers and grow into a reliable backend developer. If that sounds like a fit, I'd love to hear from you.
