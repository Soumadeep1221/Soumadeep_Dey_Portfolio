## Features

- Terminal and IDE-inspired windows with an emerald green accent
- Infinite project slideshow that pauses on hover (one card at a time on mobile)
- Typewriter headline, scroll-reveal animations and an animated tech-stack grid
- Fully responsive, with a mobile navigation menu
- Respects `prefers-reduced-motion` for the slideshow
- Lightweight: about 700 KB in total, with optimized images
- Contact form powered by Web3Forms, so no backend is needed

## Run Locally

No installation needed. Clone the repo and open `index.html` in your browser:

```bash
git clone https://github.com/Soumadeep1221/<repo-name>.git
cd <repo-name>
```

Or serve it with any static server:

```bash
npx serve .
# or
python -m http.server 8000
```

## Customize

| To change | Where |
|---|---|
| Text and links | The matching section in `index.html` |
| Projects | Each project is a `.project-card` inside `.slider-track`. Add or remove cards and the slideshow adapts. |
| Slide direction and speed | `DIR`, `GAP_MS` and `SLIDE_MS` at the top of the slideshow block in `js/script.js` |
| Colors | CSS variables at the top of `css/style.css` (`--g` is the accent color) |
| Contact form | Replace the `access_key` value with your own key from [web3forms.com](https://web3forms.com) |

---

## Deploy

This is a static site, so it deploys anywhere without a build step. On Vercel or Netlify, import the repo, leave the build command empty and use the repo root as the output directory.
